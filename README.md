# Bank System — OOP

A console-based **Bank Management System** built in **C++** using **OOP** principles.

## About

This project simulates core banking operations — managing client accounts, deposits, withdrawals, and transfers — implemented using C++ classes and object-oriented design.

## Features

- Add and manage client accounts
- Deposit and withdraw funds
- Transfer money between accounts
- View account balance and details
- Login system with PIN validation
- File-based data persistence

## Tech Stack

- **Language:** C++
- **Paradigm:** OOP — classes, encapsulation, data hiding
- **Storage:** File handling (`fstream`)

## Getting Started

```bash
g++ -std=c++11 -o BankSystem BankSystem_OOP.cpp
./BankSystem
```

Or open the `.sln` file in **Visual Studio** and run with `F5`.

## Concepts Demonstrated

- OOP encapsulation and data hiding
- Class design for real-world entities (Client, Account)
- File handling for data persistence
- Console menu-driven interface
